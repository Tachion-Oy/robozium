# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue.

Use GitHub's
[private vulnerability reporting](https://github.com/Tachion-Oy/robozium/security/advisories/new)
to send the affected commit or version, impact, reproduction steps, and any
suggested remediation. Include the operating system and mock/live mode, plus
Docker/Compose versions or native development versions when relevant. Remove
credentials and unrelated private project data from the report.

If private reporting is unavailable, open an issue asking maintainers for a
private contact without disclosing the vulnerability.

## Supported development line

The project is early-stage software. Security fixes are made on the current
development line; older development snapshots are not maintained as separate
supported branches.
