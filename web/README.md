# Robozium frontend

Next.js terminal UI for the Robozium API. Use the Docker launcher documented
in the repository root.

See [frontend architecture](../docs/frontend-architecture.md) for component ownership, data flow, and placement rules.

The brand and fixed display labels use complete Pirulen outline artwork in
`public/branding`. The source font is not distributed or loaded by the browser.
The HUD retains the original Anurati A status mark. Pirulen is by Raymond
Larabie; see the [font page](https://www.1001fonts.com/pirulen-font.html)
and [desktop usage terms](https://typodermicfonts.com/license/).
